# 前端转后端系统学习课程目录

## 阶段一：Java 核心基础（3-4 周）★★★★★

> 后端面试的第一道门。HashMap 源码、AQS 原理、synchronized 锁升级几乎每场面试必问。
> 跳过这步后面什么都学不扎实。

| 编号 | 课程标题 | 核心知识点 | 学时 | 掌握程度 | 状态 |
|------|----------|------------|------|----------|------|
| 1-1 | JDK 核心类源码精读（上） | Object equals/hashCode/clone 契约；String byte[] 存储与编码；StringBuilder vs StringBuffer；Enum 语法糖与枚举单例 | 6h | 掌握 | ✅ |
| 1-2 | JDK 核心类源码精读（下） | Throwable/Exception/Error 异常体系；Class 反射基础；ClassLoader 双亲委派与 SPI；System 流与时间 | 6h | 掌握 | ✅ |
| 1-3 | Java 8 Stream 流式编程 | 三段式结构与惰性求值；中间/终端操作全家桶；collect 家族与 toMap 坑；方法引用四种形态；并行流 | 5h | 熟悉 | ✅ |
| 1-4 | Optional 与泛型实战 | Optional 创建/消费链与 orElse vs orElseGet；泛型三用法；PECS 通配符；常见泛型签名解读 | 4h | 熟悉 | ✅ |
| 1-5 | JDK IO 与 NIO | InputStream/OutputStream/Reader/Writer 体系；Buffer 四大标记；ByteBuffer 直接内存 vs 堆内存；File/URI/URL | 5h | 熟悉 | ⬜ |
| 1-6 | Java 集合框架 — List & Queue | ArrayList 动态扩容与 fail-fast；LinkedList 双向链表；Vector & Stack；PriorityQueue 堆结构；ArrayDeque 循环数组 | 5h | 掌握 | ⬜ |
| 1-7 | Java 集合框架 — Map | HashMap 数组+链表+红黑树；ConcurrentHashMap CAS+synchronized；TreeMap 红黑树；LinkedHashMap LRU；HashTable | 6h | 掌握 | ⬜ |
| 1-8 | JUC 并发基础 — 锁与同步 | synchronized 偏向锁→轻量级→重量级升级；volatile 可见性与禁止重排；ReentrantLock 公平/非公平；ReadWriteLock | 6h | 掌握 | ⬜ |

| 1-10 | JUC 线程池 | ThreadPoolExecutor 七参数与执行流程；Executors 的坑；ScheduledThreadPoolExecutor；ForkJoinPool；CompletableFuture | 5h | 掌握 | ⬜ |
| 1-11 | JUC 并发原理深挖 | AQS 源码 state+CLH 队列；Thread 生命周期；synchronized Mark Word 实现；happens-before 原则 | 4h | 掌握 | ⬜ |
