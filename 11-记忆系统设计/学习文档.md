# 第11节：记忆系统设计

## 一、本节定位

Agent 执行多步任务时，中间信息不断堆积，上下文窗口很快撑爆。本节解决：**信息怎么存、怎么取、什么时候压缩、怎么防止记忆腐蚀？**

---

## 二、两种记忆类型

### 2.1 短期记忆（Short-Term Memory）

短期记忆就是当前上下文窗口，包含：系统指令、对话历史、工具调用结果、当前推理状态。

| 特点   | 说明                  |
| ---- | ------------------- |
| 存储   | LLM 上下文窗口内          |
| 速度   | 极快（无需额外检索）          |
| 容量   | 有限（128K-200K token） |
| 生命周期 | 单次会话                |

### 2.2 长期记忆（Long-Term Memory）

长期记忆持久化存储在外部，跨会话保留。

| 特点   | 说明                |
| ---- | ----------------- |
| 存储   | 向量数据库、关系数据库、KV 存储 |
| 速度   | 需要检索（毫秒级）         |
| 容量   | 理论上无限             |
| 生命周期 | 跨会话持久化            |

### 2.3 类比

| 人脑记忆 | Agent 记忆 | 实现         |
| ---- | -------- | ---------- |
| 工作记忆 | 短期记忆     | 上下文窗口      |
| 长期记忆 | 长期记忆     | 向量数据库 + 检索 |

## 三、短期记忆：上下文压缩

### 3.1 滚动压缩策略

```
完整对话历史 (8000 tokens):
  [轮次1-10]  → 压缩为摘要 (300 tokens)
  [轮次11-15] → 压缩为摘要 (200 tokens)
  [轮次16-20] → 保留原文 (4000 tokens)  ← 最近对话不压缩
  [当前轮次]  → 原文
```

**核心原则**：最近的对话保留原文（信息密度最高），更早的逐步压缩。

### 3.2 代码实现

```python
import openai

def compress_history(messages: list, keep_recent: int = 6, max_summary_tokens: int = 300) -> list:
    """
    滚动压缩对话历史
    - keep_recent: 保留最近几轮对话的原文
    - 更早的历史用 LLM 压缩为摘要
    """
    if len(messages) <= keep_recent:
        return messages

    # 分割: 早期历史 vs 最近对话
    old_messages = messages[:-keep_recent]
    recent_messages = messages[-keep_recent:]

    # 把早期历史拼成文本
    old_text = "\n".join(
        f"{m['role']}: {m['content']}" for m in old_messages
    )

    # 用 LLM 压缩
    response = openai.chat.completions.create(
        model="gpt-4o-mini",
        messages=[{
            "role": "user",
            "content": f"请将以下对话历史压缩为一段简洁的摘要，保留关键信息、用户偏好和重要决策，不超过{max_summary_tokens}字:\n\n{old_text}"
        }],
        max_tokens=max_summary_tokens,
    )

    summary = response.choices[0].message.content

    # 返回: [摘要] + [最近原文]
    return [
        {"role": "system", "content": f"[对话历史摘要]\n{summary}"}
    ] + recent_messages


# 使用示例
messages = [
    {"role": "user", "content": "我想学Python"},
    {"role": "assistant", "content": "好的，Python入门..."},
    # ... 20轮对话 ...
    {"role": "user", "content": "那装饰器怎么用？"},
]

compressed = compress_history(messages, keep_recent=6)
print(f"压缩前: {len(messages)} 条消息")
print(f"压缩后: {len(compressed)} 条消息")
```

### 3.3 何时触发压缩

| 触发条件 | 示例 |
|----------|------|
| Token 数超阈值 | 超过窗口的 70% |
| 轮次超阈值 | 超过 15 轮 |
| 工具结果过长 | 单次工具返回 > 2000 token |

## 四、长期记忆：写入与检索

### 4.1 写入

Agent 在对话中主动判断哪些信息值得记住：

```python
import json
from datetime import datetime

class MemoryStore:
    def __init__(self):
        self.memories = []  # 生产中用向量数据库

    def add(self, content: str, memory_type: str = "episodic", metadata: dict = None):
        """写入一条记忆"""
        memory = {
            "id": len(self.memories) + 1,
            "content": content,
            "type": memory_type,  # episodic / semantic / procedural
            "timestamp": datetime.now().isoformat(),
            "metadata": metadata or {},
            "confidence": 0.8,  # 置信度
            "expires_at": None,  # 过期时间
        }
        self.memories.append(memory)
        return memory

    def search(self, query: str, top_k: int = 3) -> list:
        """检索相关记忆（简化版：生产中用向量相似度搜索）"""
        # 生产中: query → embedding → cosine similarity
        # 简化版: 关键词匹配
        results = [
            m for m in self.memories
            if any(word in m["content"] for word in query.split())
        ]
        return results[:top_k]

    def cleanup_expired(self):
        """清理过期记忆"""
        now = datetime.now().isoformat()
        self.memories = [
            m for m in self.memories
            if not m.get("expires_at") or m["expires_at"] > now
        ]


# 使用示例
store = MemoryStore()

# Agent 主动写入记忆
store.add("用户偏好用 TypeScript", memory_type="semantic")
store.add("用户正在做 LangGraph 项目", memory_type="episodic")
store.add("处理退款流程: 先查订单 → 验证金额 → 执行退款", memory_type="procedural")

# 新对话开始时检索
relevant = store.search("LangGraph 怎么用")
```

### 4.2 检索流程

```
用户输入 → 生成查询 → 向量搜索 top_k 记忆 → 拼入上下文 → LLM 推理
```

## 六、记忆腐蚀与治理

### 6.1 问题

长期运行的 Agent 积累大量记忆 → 检索噪声增大 → 有用记忆被淹没 → Agent 表现下降。

### 6.2 治理策略

| 策略 | 说明 |
|------|------|
| 过期机制 | 临时记忆设 TTL，到期自动清理 |
| 置信度衰减 | 长期未被检索的记忆降低置信度 |
| 定期合并 | 把碎片记忆合并为更高层级的摘要 |
| 去重 | 语义相似的记忆只保留一条 |
| 主动遗忘 | 低置信度 + 长期未检索 → 删除 |

## 七、面试高频题

### 题目 1：Agent 的短期记忆和长期记忆有什么区别？

**标准答案**：短期记忆就是上下文窗口，存放当前对话的指令、历史、工具结果，速度快但容量有限（128K-200K token），会话结束就消失。长期记忆持久化在外部（向量数据库等），跨会话保留，容量大但需要检索。类比人脑：短期记忆是工作记忆，长期记忆需要"回忆"。

---

### 题目 2：对话历史太长超出上下文窗口怎么办？

**标准答案**：滚动压缩。保留最近几轮对话的原文不动（信息密度最高），把更早的历史用 LLM 压缩成摘要。关键是"滚动"——随着对话推进，之前保留的原文也会变成被压缩的对象。触发时机一般是 token 数超过窗口 70% 或轮次超过阈值。

---

### 题目 3：Agent 的长期记忆怎么实现？

**标准答案**：写入和检索两个动作。写入是 Agent 在对话中主动判断哪些信息值得记住（用户偏好、关键决策、任务结果），存到向量数据库。检索是新对话开始时用当前问题做向量搜索，把相关的历史记忆塞进上下文。本质就是 Agent 自己的 RAG——检索的不是外部文档而是自己的历史经验。

---

### 题目 4：什么是记忆腐蚀？怎么解决？

**标准答案**：长期运行的 Agent 不断积累记忆，只加不删导致检索噪声越来越大，有用信息被过时信息淹没。解决策略：给临时记忆设过期时间、长期未被检索的记忆降低置信度、定期把碎片记忆合并为摘要、语义去重、主动遗忘低置信度记忆。核心思想：Agent 不只需要记住，还需要有选择性地遗忘。

---

### 题目 5：2026 年 Agent 记忆的四层模型是什么？

**标准答案**：工作记忆（上下文窗口，当前推理状态）、情景记忆（时间线事件，记录"上次发生了什么"）、语义记忆（事实知识，如"Python列表可变"）、程序记忆（流程技能，如"退款流程: 查单→验证→退款"）。这四层对应人脑的不同记忆系统，面试说出这个分法能体现你跟进了前沿研究。
