# 删除有序数组中的重复项

> 来源：LeetCode 26
> 日期：2026-08-02
> 难度：简单

## 题目描述

给定一个非递减排列的数组 nums，要求原地删除重复出现的元素，每个元素只出现一次，保持相对顺序不变，返回唯一元素的个数 k。

## 解题思路

### 核心知识点

- 读写双指针：p 指向写入位置，i 从前往后扫，遇到不同的元素就写入 p 的位置
- 有序数组的特性：重复元素一定相邻，只需和上一个写入的元素比较
- 索引转长度：返回 p + 1

### 步骤拆解

1. p = 0，第一个元素默认保留
2. i 从 1 遍历到末尾，比较 nums[i] 和 nums[p]
3. 不同则 p++，nums[p] = nums[i]
4. 返回 p + 1

## 最终代码

```java
class Solution {
    public int removeDuplicates(int[] nums) {
        int p = 0;
        for (int i = 1; i < nums.length; i++) {
            if (nums[i] != nums[p]) {
                p++;
                nums[p] = nums[i];
            }
        }
        return p + 1;
    }
}
```

## 踩过的坑

- 无，一次写对

## Java API 笔记

- `for (int i = 1; i < nums.length; i++)`：三部分顺序正确，从 1 开始遍历
- `nums.length`：数组长度属性

## 一句话总结

读写双指针去重：p 指向写入位置，遇到不同的就 p++ 再写入，返回 p+1。与 LC27 首尾双指针是同一题的两种解法，保序用读写双指针，不保序用首尾双指针。
