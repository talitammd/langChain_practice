# 删除有序数组中的重复项 II

> 来源：LeetCode 80
> 日期：2026-08-02
> 难度：中等

## 题目描述

给你一个升序排列的数组 nums，要求原地删除重复元素，使每个元素最多出现两次，返回新长度。O(1) 额外空间。

## 解题思路

### 核心知识点

- 读写双指针（通用化）：从 LC26 的"保留 1 个"扩展到"保留 2 个"
- 比较距离参数化：LC26 用 `nums[p]`（和上一个比），LC80 用 `nums[p - 2]`（和上上一个比）
- `nums[p - 2]` 的含义：p 是下一个写入位置，p-2 就是两个位置之前，如果相同说明已经写了两个了

### 步骤拆解

1. p = 2，前两个元素默认保留
2. i 从 2 遍历到末尾，比较 nums[i] 和 nums[p - 2]
3. 大于（新值）才写入 nums[p]，p++
4. 返回 p（p 本身就是长度，因为初始值是 2 不是 0）

## 最终代码

```java
class Solution {
    public int removeDuplicates(int[] nums) {
        int p = 2;
        for (int i = 2; i < nums.length; i++) {
            if (nums[i] > nums[p - 2]) {
                nums[p] = nums[i];
                p++;
            }
        }
        return p;
    }
}
```

## 踩过的坑

- 无编译错误，但最初对 `nums[p - 2]` 的作用不理解：为什么比较上上一个就能保证最多两个

## Java API 笔记

- 无新增 API，巩固了 for 循环和数组操作

## 一句话总结

读写双指针的"保留 N 个"通用模式：p 初始值为 N，比较条件用 `nums[p - N]`，循环从 N 开始。LC26 是 N=1，LC80 是 N=2。
