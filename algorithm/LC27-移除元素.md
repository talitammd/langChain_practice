# 移除元素

> 来源：LeetCode 27
> 日期：2026-08-02
> 难度：简单

## 题目描述

给你一个数组 nums 和一个值 val，要求原地移除所有等于 val 的元素，把不等于 val 的元素挤到数组前面，返回剩余元素个数 k。顺序可以改变。

## 解题思路

### 核心知识点

- 首尾双指针：i 从前往后扫，p 从后往前收缩，遇到 val 就把末尾元素搬过来填充
- 关键细节：搬过来后 i 不动，重新检查新元素是否也等于 val
- 与读写双指针的对比：读写双指针保序但需要遍历全部元素，首尾双指针不保序但更快

### 步骤拆解

1. i = 0，p = nums.length - 1
2. while (i <= p)：如果 nums[i] == val，用 nums[p] 覆盖 nums[i]，p--，i 不动
3. 如果 nums[i] != val，i++
4. 返回 p + 1（索引转长度）

## 最终代码

```java
class Solution {
    public int removeElement(int[] nums, int val) {
        int p = nums.length - 1;
        int i = 0;

        while (i <= p) {
            if (nums[i] == val) {
                nums[i] = nums[p];
                p--;
            } else {
                i++;
            }
        }
        return p + 1;
    }
}
```

## 踩过的坑

- 第一版 for 循环三个部分顺序写反：`for (int i=0; i++; i==p)`，正确是 `for (初始化; 条件; 更新)`
- 用 for 循环无法实现"搬过来后不 i++"，因为 for 每次必定 i++，需要改用 while 手动控制
- 中间版本逻辑过度复杂，加了嵌套 while 循环和多余判断，反而引入更多 bug
- 数组赋值语句少写分号导致编译失败

## Java API 笔记

- `for (int i = 0; i < n; i++)`：三部分顺序是 初始化、条件、更新
- `while (条件)`：适合需要手动控制步进的场景
- `if-else`：语句块 `{}` 后面不需要加分号

## 一句话总结

首尾双指针移除元素的关键是：搬过来后 i 不动重新检查，循环结束返回 p+1（索引转长度）。
