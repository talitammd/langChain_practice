# 多数元素

> 来源：LeetCode 169
> 日期：2026-08-02
> 难度：简单

## 题目描述

给定一个大小为 n 的数组 nums，返回其中出现次数大于 ⌊n/2⌋ 的多数元素。数组非空且一定存在多数元素。

## 解题思路

### 核心知识点

- 投票法（Boyer-Moore Majority Vote）：多数元素超过一半，所有不同元素互相抵消后，最后剩下的一定是多数元素
- 时间 O(n)，空间 O(1)
- 投票法专门用于找"出现次数超过 n/2"的元素，可扩展至 n/3（用两个候选人）

### 步骤拆解

1. count = 0，pick = nums[0]
2. 遍历数组：count 为 0 时换候选人为当前元素
3. 当前元素等于候选人则 count++，否则 count--
4. 返回 pick

## 最终代码

```java
class Solution {
    public int majorityElement(int[] nums) {
        int count = 0;
        int pick = nums[0];
        for (int i = 0; i < nums.length; i++) {
            if (count == 0) {
                pick = nums[i];
            }
            if (nums[i] == pick) {
                count++;
            } else {
                count--;
            }
        }
        return pick;
    }
}
```

## 一句话总结

投票法利用"多数元素超过一半"的特性，不同元素互相抵消，最后剩下的一定是多数元素，O(n) 时间 O(1) 空间。
