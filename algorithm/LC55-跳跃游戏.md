# 跳跃游戏

> 来源：LeetCode 55
> 日期：2026-08-05
> 难度：中等

## 题目描述

给定一个非负整数数组 nums，最初位于第一个下标，每个元素代表该位置可跳跃的最大长度。判断是否能到达最后一个下标。

## 解题思路

### 核心知识点

- 贪心——维护最远可达位置：一边遍历一边更新"目前能到达的最远位置"
- 判断顺序：先检查当前位置是否在可达范围内，再更新最远距离
- 两个步骤必须分开，不能合并到一个 if 里

### 步骤拆解

1. maxReach = 0
2. 遍历每个位置 i：先判断 i > maxReach，如果到不了当前位置直接返回 false
3. 更新 maxReach = max(maxReach, i + nums[i])
4. 如果 maxReach >= len - 1，能到终点返回 true
5. 循环结束返回 true（能走到最后说明都可达）

## 最终代码

```java
class Solution {
    public boolean canJump(int[] nums) {
        int maxReach = 0;
        for (int i = 0; i < nums.length - 1; i++) {
            if (i > maxReach) {
                return false;
            }
            maxReach = Math.max(maxReach, i + nums[i]);
            if (maxReach >= nums.length - 1) {
                return true;
            }
        }
        return maxReach >= nums.length - 1;
    }
}
```

## 踩过的坑

- 第一版用"从当前位置能跳多远"直接判断终点，没有维护 maxReach，逻辑不完整
- 第二版更新了 maxReach 但没判断"当前位置是否可达"，走到不可达的位置仍然更新了 maxReach
- 第三版试图把"检查可达"和"更新 maxReach"合在一个 if 里，导致不可达的位置仍然被处理
- 用了 `&` 而不是 `&&`，Java 中 `&&` 是短路运算更安全
- 用三元运算符 `? true : false`，条件本身已经是 boolean 不需要转换

## Java API 笔记

- `Math.max(a, b)`：返回两个值中较大的那个，比手写 if 更简洁
- `&&`：短路逻辑与，前面为 false 就不计算后面
- `boolean` 返回类型：条件本身就是 boolean，不需要 `? true : false`

## 一句话总结

跳跃游戏的核心是维护"最远可达位置"：先判断当前位置能不能到达，再更新最远距离，三步必须分开。
