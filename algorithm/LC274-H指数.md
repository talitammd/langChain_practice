# H 指数

> 来源：LeetCode 274
> 日期：2026-08-05
> 难度：中等

## 题目描述

给定一个整数数组 citations，其中 citations[i] 表示第 i 篇论文被引用的次数。h 指数是指至少有 h 篇论文被引用次数大于等于 h，取最大的那个 h。

## 解题思路

### 核心知识点

- 排序后遍历：从小到大排序后，位置 i 到末尾有 n-i 篇论文，citations[i] 是这些论文里引用次数最低的
- h 值 = min(citations[i], n - i)，取所有位置里的最大值
- 排序是前提：不排序则"当前元素比前面大比后面小"的前提不成立

### 步骤拆解

1. Arrays.sort(citations) 从小到大排序
2. 遍历每个位置 i，计算 min(citations[i], citations.length - i)
3. 取所有结果里的最大值作为 h 指数

## 最终代码

```java
class Solution {
    public int hIndex(int[] citations) {
        int n = 0;
        Arrays.sort(citations);
        for (int i = 0; i < citations.length; i++) {
            if (citations.length - i > n) {
                n = Math.min(citations[i], citations.length - i);
            }
        }
        return n;
    }
}
```

## 踩过的坑

- 第一版忘了排序，导致"当前元素比前面大比后面小"的前提不成立，结果错误
- 用 if 过滤而非 Math.max 更新，虽然能通过但不够直觉，可简化为 n = Math.max(n, Math.min(citations[i], citations.length - i))

## Java API 笔记

- `Arrays.sort(nums)`：原地排序，从小到大，无返回值，需要 `import java.util.Arrays`
- `Math.min(a, b)`：取两个值最小值
- `Math.max(a, b)`：取两个值最大值

## 一句话总结

H 指数的关键是排序后对每个位置算 min(citations[i], n-i) 再取最大值，排序保证"当前位置到末尾的论文引用次数都 >= citations[i]"。
