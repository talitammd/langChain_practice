# 买卖股票的最佳时机

> 来源：LeetCode 121
> 日期：2026-08-05
> 难度：简单

## 题目描述

给定一个数组 prices，第 i 个元素是第 i 天的股价。只能选择某一天买入，未来某一天卖出，求最大利润。不能获利则返回 0。

## 解题思路

### 核心知识点

- 维护最小值：一边遍历一边更新最低买入价和最大利润
- 时间 O(n)，空间 O(1)

### 步骤拆解

1. minPrice = prices[0]，maxProfit = 0
2. 遍历每天：先用当前价格减 minPrice 算利润，比 maxProfit 大就更新
3. 再判断当前价格是否小于 minPrice，是则更新
4. 返回 maxProfit

## 最终代码

```java
class Solution {
    public int maxProfit(int[] prices) {
        int maxProfit = 0;
        int minPrice = prices[0];
        for (int i = 0; i < prices.length; i++) {
            if (prices[i] - minPrice > maxProfit) {
                maxProfit = prices[i] - minPrice;
            }
            if (prices[i] < minPrice) {
                minPrice = prices[i];
            }
        }
        return maxProfit;
    }
}
```

## 踩过的坑

- 无逻辑错误，一次写对

## Java API 笔记

- Java 变量命名规范：驼峰命名（camelCase），如 `maxProfit`、`minPrice`，不用下划线

## 一句话总结

买卖股票的核心是一边走一边维护"到目前为止的最低价"，每到一个新价格就算一下"如果今天卖能赚多少"，一次遍历搞定。
