# O(1) 时间插入、删除和获取随机元素

> 来源：LeetCode 380
> 日期：2026-08-10
> 难度：中等

## 题目描述

实现 RandomizedSet 类，要求 insert、remove、getRandom 三个方法均为 O(1) 平均时间复杂度。getRandom 要求每个元素等概率返回。

## 解题思路

### 核心知识点

- HashMap + ArrayList 配合：HashMap 负责 O(1) 查找判断存在，ArrayList 负责 O(1) 随机访问
- 删除优化：ArrayList 中间删除是 O(n)，末尾删除是 O(1)，所以把末尾元素搬到要删的位置再删末尾
- HashMap 存"值 → 索引"，ArrayList 存值本身

### 步骤拆解

1. insert：map 判断不存在 → arr.add(val) → map.put(val, arr.size()-1)
2. remove：map 判断存在 → 取索引 ind → 末尾搬到 ind → 更新末尾元素索引 → 删末尾 → 删 map 记录
3. getRandom：rand.nextInt(arr.size()) 生成随机索引 → arr.get(r)

## 最终代码

```java
class RandomizedSet {
    ArrayList<Integer> arr = new ArrayList<>();
    Map<Integer, Integer> map = new HashMap<>();
    Random rand = new Random();

    public RandomizedSet() {
    }

    public boolean insert(int val) {
        if (!map.containsKey(val)) {
            arr.add(val);
            map.put(val, arr.size() - 1);
            return true;
        }
        return false;
    }

    public boolean remove(int val) {
        if (map.containsKey(val)) {
            int ind = map.get(val);
            arr.set(ind, arr.get(arr.size() - 1));
            map.put(arr.get(ind), ind);
            arr.remove(arr.size() - 1);
            map.remove(val);
            return true;
        }
        return false;
    }

    public int getRandom() {
        int r = rand.nextInt(arr.size());
        return arr.get(r);
    }
}
```

## 踩过的坑

- 第一版数据结构声明在构造函数里作为局部变量，其他方法访问不到，要声明为成员变量
- 两个变量同名 arr，编译报错
- `new Map<>()` 不行，Map 是接口要写 `new HashMap<>()`
- `Math.random(0, size)` 不对，要用 `Random.nextInt(size)`
- insert 忘记更新 map，remove 忘记更新末尾元素的 map 索引
- getRandom 写成 `map.get(r)` 而非 `arr.get(r)`，map 存的是索引不是值

## Java API 笔记

- `ArrayList<Integer>`：动态列表，`add` 添加、`get` 取值、`set` 修改、`remove` 删除、`size` 取长度
- `HashMap<Integer, Integer>`：`put` 存键值对、`get` 取值、`containsKey` 判断存在、`remove` 删除
- `Random.nextInt(n)`：生成 0 到 n-1 的随机整数
- 成员变量声明在类里方法外，所有方法共享
- `Map` 是接口不能直接 new，要用 `new HashMap<>()`

## 一句话总结

HashMap + ArrayList 是经典组合：HashMap 负责 O(1) 查找，ArrayList 负责 O(1) 随机访问，删除时把末尾搬到中间再删末尾实现 O(1)。
