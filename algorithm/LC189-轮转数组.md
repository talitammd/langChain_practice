# 轮转数组

> 来源：LeetCode 189
> 日期：2026-08-05
> 难度：中等

## 题目描述

给定一个整数数组 nums，将数组中的元素向右轮转 k 个位置，k 是非负数。要求原地修改 nums。

## 解题思路

### 核心知识点

- 三次翻转法：整体翻转 → 翻转前 k 个 → 翻转剩下的，空间 O(1)
- 取模处理：k > 数组长度时用 k = k % nums.length 取实际轮转步数
- Java 不允许方法内嵌套定义方法，翻转函数必须写在类里方法外

### 步骤拆解

1. k = k % nums.length 处理 k 超过数组长度的情况
2. 翻转整个数组
3. 翻转前 k 个元素（索引 0 到 k-1）
4. 翻转剩余元素（索引 k 到末尾）

## 最终代码

```java
class Solution {
    public void patition_rotate(int start, int end, int[] nums) {
        while (start < end) {
            int temp = nums[start];
            nums[start] = nums[end];
            nums[end] = temp;
            start++;
            end--;
        }
    }

    public void rotate(int[] nums, int k) {
        if (k > nums.length) {
            k = k % nums.length;
        }

        patition_rotate(0, nums.length - 1, nums);
        patition_rotate(0, k - 1, nums);
        patition_rotate(k, nums.length - 1, nums);
    }
}
```

## 踩过的坑

- 第一版在方法内部定义翻转函数，Java 不允许方法内嵌套定义方法，必须写到类里方法外
- `nums[start]]` 多写了一个括号
- 最后一句少写分号
- 取模写反：写成 `nums.length % k`，应该是 `k % nums.length`。k=4, len=3 时，3%4=3 但正确答案是 4%3=1

## Java API 笔记

- Java 不允许方法内嵌套定义方法（与 Python 不同），辅助方法必须写在类里、方法外
- 交换两个变量必须借助 `int temp` 临时变量
- `a % b`：取模运算，a 和 b 的顺序不能搞反

## 一句话总结

轮转数组 = 取模处理 k + 三次翻转（整体、前 k 个、剩余），原地完成 O(1) 空间。
