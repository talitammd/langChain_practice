# 合并两个有序数组

> 来源：LeetCode 88
> 日期：2026-08-02
> 难度：简单

## 题目描述

给你两个按非递减顺序排列的数组 nums1 和 nums2，以及它们的有效长度 m 和 n。nums1 长度为 m+n，前 m 个是有效数据，后 n 个是 0 占位。要求把 nums2 合并到 nums1 里，原地修改不返回。

## 解题思路

### 核心知识点

- 从后往前的双指针：利用 nums1 末尾空位，三个指针从各自末尾出发，每次挑较大的放入
- 时间 O(m+n)，空间 O(1)

### 步骤拆解

1. 三个指针：p = m+n-1（填入位置），p1 = m-1（nums1 有效末尾），p2 = n-1（nums2 末尾）
2. 循环比较 nums1[p1] 和 nums2[p2]，较大的放到 nums1[p]，对应指针前移
3. nums2 全部填完后直接结束（nums1 剩余数据已在原位）

## 最终代码

```java
class Solution {
    public void merge(int[] nums1, int m, int[] nums2, int n) {
        int p = m + n - 1;
        int p1 = m - 1;
        int p2 = n - 1;

        while (p >= 0) {
            if (p2 < 0) {
                return;
            }
            if (p1 >= 0 && nums1[p1] >= nums2[p2]) {
                nums1[p] = nums1[p1];
                p1--;
            } else {
                nums1[p] = nums2[p2];
                p2--;
            }
            p--;
        }
    }
}
```

## 踩过的坑

- 第一版加了 `if (p1 == 0) { nums1 = nums2; return }`，但 p1=-1 时不等于 0，分支进不去；而且 Java 里 `nums1 = nums2` 只是改变局部变量指向，不会修改原数组内容。
- 第二版用 `p1 < 0 || nums1[p1] >= nums2[p2]` 作为条件，但 p1<0 时走 if 分支访问了 `nums1[-1]`，数组越界。同时没处理 p2<0 的情况。
- 第三版条件改为 `p1 >= 0 && nums1[p1] >= nums2[p2]`，正确防止了 p1 越界，但没处理 p2 先减到 -1 时 `nums2[-1]` 越界的问题。
- 最终版加 `if (p2 < 0) return` 提前退出，解决 p2 越界。可简化为 `while (p2 >= 0)`。
- `return` 少写分号导致编译失败。

## Java API 笔记

- `nums.length`：数组长度属性，不加括号
- 数组赋值和读取：`nums[i] = val`，`val = nums[i]`
- `while (条件)`：条件为 true 时循环，适合不确定循环次数的场景
- Java 每条语句必须以 `;` 结尾

## 一句话总结

从后往前双指针合并有序数组，注意防止指针越界——p1 和 p2 都可能先到 -1，要分别处理。
